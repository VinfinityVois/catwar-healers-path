## О скрипте

**Тропа Целителя** — userscript для игры **CatWar**, который превращает роль целителя из бесконечного открывания вики в удобную панель прямо в игре: справочник трав и болезней, автоматический калькулятор лечения, костоправы, смеси и подсказки по сортировке ресурсов.

Плавающая иконка ⚕ открывает перетаскиваемую панель, которая запоминает своё положение и размер и не мешает игровому интерфейсу.

---

## ✨ Возможности

| Раздел | Что внутри |
|---|---|
| 🩹 **Болезни** | Причины, визуальные признаки, лечение — с превью модели кота по стадиям (взрослый / котёнок) |
| 🌱 **Травы** | Полный список с иконками, рецептами подготовки и % лечения, фильтр по типу травмы |
| 🧮 **Калькулятор** | Расчёт нужного количества трав под текущий ЦУ и HP, свой набор трав, автоподбор оптимального варианта |
| 🦴 **Костоправ** | Расчёт хила по таблице (луны × часы), лимит по возрасту, сравнение вьюнкового и паутинного рецептов |
| 📋 **Действия** | Пошаговые рецепты приготовления каждой травы — что разделить, разжевать, наложить |
| 📖 **Памятка** | Таблицы роста по лунам, лимитов костоправов и степеней переломов — под рукой, без вкладок вики |
| ⏱️ **Рот / скоропорт** | Подсказки, через сколько испортится трава во рту |

## 🚀 Установка

1. Поставьте менеджер userscript'ов:
   - [Tampermonkey](https://www.tampermonkey.net/) — рекомендуется
   - [Violentmonkey](https://violentmonkey.github.io/) — тоже подходит

2. Нажмите кнопку установки:

   <p align="left">
     <a href="https://raw.githubusercontent.com/VinfinityVois/catwar-healers-path/main/cwh-toolkit.user.js">
       <img src="https://img.shields.io/badge/⬇️_Установить_Тропу_Целителя-2e7d32?style=for-the-badge" alt="Установить">
     </a>
   </p>

3. Менеджер скриптов сам предложит установку — подтвердите её.
4. Зайдите в игру → внизу справа появится иконка ⚕ — это и есть панель.

---

## 🔄 Обновления

Скрипт обновляется **автоматически**: Tampermonkey/Violentmonkey периодически проверяют `@updateURL` и подтягивают новую версию сами.

Если хотите обновить вручную прямо сейчас:
- Откройте панель менеджера скриптов → найдите «Тропа Целителя» → **Проверить обновления**
- Либо просто откройте [ссылку установки](https://raw.githubusercontent.com/VinfinityVois/catwar-healers-path/main/cwh-toolkit.user.js) заново

---

## 🖱️ Как пользоваться

- **Клик по значку ⚕** — открыть/закрыть панель
- **Перетаскивание за шапку** — переместить панель
- **Уголок панели** — изменить размер
- **`–` в шапке** — свернуть в компактный режим (удобно во время дежурства)
- Все настройки (позиция, размер, уровень ЦУ, фильтры) сохраняются между сессиями
