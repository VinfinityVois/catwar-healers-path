## 📌 О проекте

**Healer's Path** — это пользовательский скрипт, созданный для облегчения работы целителей и их учеников. Скрипт автоматизирует рутинные вычисления, помогает быстро проводить диагностику заболеваний и подбирать нужные травяные смеси прямо во время игры.

---

## ✨ Основные возможности

* **🧮 Калькулятор ЦУ:** Быстрый расчет целительских условных единиц и необходимого количества трав/дозировок.
* **🌿 Справочник Трав и Смесей:** База знаний по травам, их действиям и рецептам приготовления сборов.
* **🩹 Диагностика Болезней и Переломов:** Быстрый поиск по симптомам, видам травм и методам лечения.
* **📊 Интерактивный UI:** Удобное компактное меню, интегрируемое непосредственно в интерфейс игры.

## 🚀 Установка

1. Установите менеджер скриптов для вашего браузера:
   * [Tampermonkey](https://www.tampermonkey.net/) *(рекомендуется)*
   * [Violentmonkey](https://violentmonkey.github.io/)
2. Установите скрипт напрямую из репозитория:
   * 👉 **[Нажмите здесь для установки](https://github.com/ВАШ_НИКНЕЙМ/catwar-healers-path/raw/main/healers-path.user.js)**
3. Подтвердите установку в открывшемся окне плагина.
