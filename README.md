# 🌿 Тропа Целителя

UserScript для игры **CatWar** — справочник болезней, трав, калькулятор ЦУ, костоправов и смесей.

## 🚀 Установка

1. Установите менеджер скриптов:
   - [Tampermonkey](https://www.tampermonkey.net/) (рекомендуется)
   - [Violentmonkey](https://violentmonkey.github.io/)

2. Нажмите кнопку ниже — откроется окно установки скрипта:

   👉 **[Установить Тропу Целителя](https://raw.githubusercontent.com/VinfinityVois/catwar-healers-path/main/cwh-toolkit.user.js)**

## 📋 Что умеет

- Калькулятор лечения (раны, отравление, грязь, кашель)
- Справочник трав с иконками и рецептами
- Калькулятор костоправа (вьюнковый / паутинный)
- Визуальные модели травм (взрослые / котята, 4 стадии)
- Смесь от кашля (70%)

## 🔄 Обновления

Скрипт обновляется автоматически через Tampermonkey/Violentmonkey.  
При ручной установке просто откройте ссылку повторно.
